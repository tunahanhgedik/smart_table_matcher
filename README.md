# 🎯 Smart Table Matcher (GDG Campus Match)

Bu depo, Google Developer Groups (GDG) etkinlikleri kapsamında katılımcıları eşleştirmek için tasarlanan **Smart Table Matcher** projesinin frontend dosyalarını içermektedir. Arayüz tasarımları Stitch üzerinden koda dökülmüş olup, projedeki her bir ekran bağımsız bir klasör olarak organize edilmiştir.

## 📂 Proje Yapısı

Tasarımda yer alan her sayfa (giriş, sohbet tarzı, ilgi odak alanları, etkinlik beklentileri vb.) kendi ismini taşıyan ayrı bir klasörde tutulmaktadır. Klasörlerin içeriği standart olarak şu şekildedir:

*   **`code` (.html):** O sayfaya ait frontend kaynak kodu (HTML/CSS).
*   **`screen` (.png):** O sayfanın referans tasarım önizlemesi.

**Örnek Ağaç Yapısı:**
```text
📁 1._ad_m_giri_ve_ho_geldin_mobil/
├── 📄 code (HTML belgesi)
└── 🖼️ screen (PNG ekran görüntüsü)
